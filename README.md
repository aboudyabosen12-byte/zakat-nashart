# لجنة زكاة نشرت — على GitHub (مجاني)

الواجهة بتتفتح من أي مكان على **GitHub Pages**، والبيانات بتتخزن في **مستودع خاص** على GitHub، وكل المستخدمين بيشوفوا نفس البيانات.
كل عملية بتتسجل باسم صاحبها في تاريخ المستودع (سجل النشاط جوه البرنامج للمدير).

## الإعداد (مرة واحدة، حوالي 10 دقايق)

**1) اعمل مستودعين على GitHub**
- `zakat-nashrat` — **Public** (فيه ملفات البرنامج فقط، مفيهوش أي بيانات).
- `zakat-nashrat-data` — **Private** ✅ وعلّم على «Add a README file». هنا بتتخزن البيانات.

**2) ارفع ملفات البرنامج** على `zakat-nashrat`: Add file ← Upload files، واسحب كل محتويات المجلد ده (index.html و sw.js و manifest.webmanifest وفولدرات fonts و libs و icons وملف native.bundle.js).

**3) فعّل GitHub Pages:** Settings ← Pages ← Source: *Deploy from a branch* ← Branch: `main` / `(root)` ← Save.
بعد دقيقة رابطك هيبقى: `https://اسم-حسابك.github.io/zakat-nashrat/`

**4) اعمل رمز الوصول (Token) للبيانات فقط:**
GitHub ← صورتك ← Settings ← Developer settings ← Personal access tokens ← **Fine-grained tokens** ← Generate new token
- Repository access: **Only select repositories** ← `zakat-nashrat-data`
- Permissions ← Repository permissions ← **Contents: Read and write**
- Expiration: أطول مدة متاحة (سنة). انسخ الرمز.

**5) افتح الرابط:** هيظهر «ربط الجهاز». افتح «أنا المدير» واكتب:
`اسم-حسابك/zakat-nashrat-data` + الرمز + اسمك + رقمك السري (4 إلى 10 أرقام) ← **اتصال** ← ادخل باسمك ورقمك.

**6) أضف الباقي:** تبويب «المستخدمون والنشاط» ← أضف كل شخص باسمه ورقمه وصلاحيته ← اضغط «📋 رمز إعداد جهاز جديد» وابعته له (واتساب مثلاً). هو يلصقه في أول فتحة، وبعدها يدخل باسمه ورقمه.

**7) تثبيت التطبيق:** من Chrome على الموبايل: ⋮ ← «تثبيت التطبيق». على الكمبيوتر: أيقونة التثبيت في شريط العنوان.

## لازم تعرف (بصراحة)

- **«رمز الإعداد» = مفتاح البيانات.** أي حد معاه يقدر يفتح المستودع ويقرا ويعدّل مباشرة من GitHub، حتى من غير رقم سري. الأرقام السرية بتحدد «مين» جوه البرنامج وبتمنع الاستخدام العادي، لكنها مش حماية قوية. ابعت الرمز لناس موثوقة بس.
- **قطع وصول شخص:** تعطيله من «المستخدمون» بيمنعه من البرنامج، لكن لو معاه الرمز يفضل يقدر يدخل المستودع. لو الموضوع حساس: ولّد رمز جديد من GitHub واحذف القديم، ووزّع رمز إعداد جديد.
- **سجل النشاط** بيعتمد على رسائل الـ commits. كويس للمتابعة بين ناس موثوقين، لكن مش دليل قانوني (حامل الرمز تقنياً يقدر يتلاعب). وفي الوضع ده **دخول وخروج المستخدمين مش بيتسجلوا**، بس العمليات.
- **الرمز بينتهي** (أقصى مدة سنة). لو ظهرت رسالة «رمز GitHub غير صالح أو منتهي» اعمل رمز جديد ووزع رمز إعداد جديد.
- **البيانات** (أسماء وأرقام مستفيدين) موجودة على سيرفرات GitHub في مستودع خاص.
- كل عملية حفظ بتكتب كل البيانات في commit جديد، فكل نسخة قديمة موجودة في تاريخ المستودع وتقدر ترجع لها.
- لو عاوز حماية حقيقية بأرقام سرية ينفذها سيرفر (مش مجرد واجهة)، استخدم نسخة السيرفر `zakat-nashrat-web`.
